Controller scale rule

Do not scale on value alone. Each workflow must clear a named scale gate covering process ownership, exception controls, training readiness, data-source stability, and compliance boundaries.

Presentation line: “The strongest workflow is not necessarily the highest-value workflow; the strongest workflow is the one with value, controls, owners, and a documented scale path.”

Best-Practice Scale Criteria

Pilot-to-Scale Gate

  • Process owner named: accountable owner and backup confirmed.
  • Exception rate below 12%: or a named root-cause sprint is active.
  • Training above 80%: role-based job aids and office hours available.
  • Control path documented: policy interpretation and escalation thresholds approved.
  • Dashboard source stable: metric definition, source system, and refresh cadence signed off.

30 / 60 / 90-Day Deep Dive

  • Days 1-30: validate data, reason codes, and school/unit variance.
  • Days 31-60: expand to a controlled cohort and monitor exception aging weekly.
  • Days 61-90: decide scale / hold / redesign using adoption, value, and control evidence.
  • Decision package: show benefit, tradeoff, owner, risk if delayed, and scale criteria status.
