Combined recommended action path

  • Start with the variance signal: identify whether the issue is structural salary pressure, temporary coverage, timing savings, grant/restriction exposure, inter-entity allocation friction, capital drag, reserve-floor pressure, recruiting-system timing risk, salary-baseline mismatch, seasonal noise, or silent data failure.
  • Validate the source: run API/schema checks, ARIeS vs. Careers@Harvard / ATS feed reconciliation, central-to-local reconciliation, immutable FY snapshot comparison, and source-owner confirmation before escalating numbers.
  • Normalize the baseline: compare advertised hiring range, budget salary, current salary, and forecast salary; then apply a three-year cyclic overlay so Q1, Q2, and Q4 seasonality does not look like a structural trend.
  • Classify the funding: assign Tier 1 / Tier 2 / Tier 3 reliability, separate restricted from flexible funds, and require bridge plans for soft-money cliff lines.
  • Reconcile cross-school economics: normalize tuition splitting, joint appointments, multi-tub ICR sharing, cross-registration flows, and shared-program costs before assigning local margin.
  • Apply academic-finance controls: test ICR yield, wet/dry lab cost-per-square-foot, recharge-rate compliance, net tuition elasticity, global subrecipient exposure, internal lending impact, FCI exposure, and deferred-maintenance burden.
  • Stress-test sustainability: model endowment payout shocks, federal funding shifts, inflation, tuition elasticity, reserve-floor breaches, equipment obsolescence, and fully allocated academic portfolio margins.
  • Decide through governance: use blocker rules for blanks/unmapped joins, MAPE / C-index scorecards, k<5 privacy suppression, RLS-gated drill-through, human-in-the-loop review, and academic-diplomacy adoption gates; no automated staffing, funding, portfolio, or policy decisions.

import pandas as pd
import numpy as np

def calculate_wmaf(headcount, fy26_vol, fy25_vol, fy26_invol,
                   retirement_count, low_engagement_count):
    alpha = (
        0.5 * np.array(fy26_vol) +
        0.3 * np.array(fy25_vol) +
        0.2 * np.array(fy26_invol)
    )
    base_attrition = np.array(headcount) * alpha
    climate_adjustment = np.array(low_engagement_count) * 0.15
    projected_turnover = (

📊 Engagement score

Engagement is modeled as a 0–100 index using anonymized pulse dimensions. Unit scores are weighted averages of business partner support, workload balance, belonging, clarity, and growth opportunity.

Unit engagement = Σ(dimension score × dimension weight) / Σ(weights)
Overall engagement = Σ(unit engagement × active records) / Σ(active records)
Point change = current score − prior-year score

👥 Portfolio, open/pending & active rate

Position portfolio, active records, and open/pending items are modeled at the record level. Open/Pending rate and fill rate should be calculated from the authorized position register, not from budget totals alone.

Open/pending roles = Position portfolio − Filled positions
Filled rate = Filled positions / Position portfolio
Vacancy / pending rate = Open roles / Position portfolio

🤝 Casework and policy risk scoring

Risk levels are based on a point model that weighs severity, days open, partner involvement, employee/service impact, repeat pattern, and documentation quality.

Risk score = severity points + aging points + partner/escalation points + repeat-pattern points + documentation-gap points
High ≥ 75 · Medium 45–74 · Low / monitor < 45

💵 Budget vs. forecast payroll

Forecast payroll is derived from raw position rows. Active service/role records use current salary plus projected adjustment; open/pending records use the budgeted salary adjusted by expected start date and leave/hiring bridge offset assumptions.

Filled forecast = current salary × (1 + projected adjustment %)
Open / Pending forecast = budget salary × active-months factor + leave/hiring bridge offset
Variance = budget salary − forecast salary

📉 WMAF turnover, attrition & retirement forecast

The refined formula separates historical base attrition, known retirement pipeline, and climate/workload stress. It is a planning model for workforce continuity, budget, service-risk, and leadership discussion—not an employee-level prediction tool.

Projected Attrition T_next = Σ(Hᵢ × αᵢ) + R₁₂ + C₁₂
αᵢ = 0.5×Voluntary Rate_FY26 + 0.3×Voluntary Rate_FY25 + 0.2×Involuntary Rate_FY26
R₁₂ = known retirement pipeline within 12 months
C₁₂ = roles with engagement score <65 × 0.15

Scoring rubric used in popups

Risk point guide

  • Severity: 0–30 points based on employee, policy, operational, or reputational impact.

  • Pattern: 0–15 points for repeat signals in one unit or job family.
  • Exposure: 0–20 points for finance, service-continuity, policy, or service impact.
  • Control gap: 0–15 points for missing documentation, owner, or next action.

  • Medium: 45–74 points; needs monitoring plus unit leader / partner action.
  • Monitor: below 45 points; keep in trend view or next scheduled review.
